# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
pnpm dev          # start dev server
pnpm build        # type-check + build to dist/
pnpm lint         # ESLint
pnpm preview      # preview production build
```

## Tech Stack

- **React 19** + **Vite 8** + **TypeScript 6**
- **Tailwind CSS v4** via `@tailwindcss/vite` (no `tailwind.config.js` — config lives in `src/index.css` under `@theme inline`)
- **shadcn/ui** (`radix-nova` style, CSS variables, `@/components/ui/`)
- **Radix UI** primitives, **Lucide React** icons, **tw-animate-css**
- Path alias: `@/` → `src/`

## Design Reference

All visual designs live in `claude-design/` and are the source of truth for UI:

| File | Screen |
|------|--------|
| `claude-design/Portal.html` | User-facing portal (login, dashboard) |
| `claude-design/Cipher.html` | Main cipher/agent interface |
| `claude-design/Admin.html` | Admin panel |
| `claude-design/app/ui.css` | Shared design tokens & component CSS |
| `claude-design/app/ui.js` | Shared JS utilities |

**Always consult `claude-design/` when implementing or styling a feature.** These HTML files are generated by Claude Design and define colors, spacing, typography, and component patterns for this project.

### Design tokens (from `claude-design/app/ui.css`)

- **Primary**: violet `hsl(252 100% 65%)` / `#6b4eff`
- **Fonts**: IBM Plex Sans (UI), IBM Plex Mono (technical/DID strings), Instrument Serif (accent)
- **Background**: warm off-white in light mode, near-black in dark mode
- Token names follow shadcn conventions (`--primary`, `--muted`, `--destructive`, etc.)

> The tokens in `src/index.css` are the neutral shadcn defaults and should be overridden to match `claude-design/app/ui.css` as screens are implemented.

## Adding shadcn Components

```bash
pnpm dlx shadcn@latest add <component>
```

Components land in `src/components/ui/`. Do not hand-edit generated shadcn files unless matching the claude-design spec requires it.
